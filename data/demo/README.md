# Демо-данные

Два демо-проекта для показа прототипа без весов модели. Снимки синтетические (ТЗ, раздел 6.2, допускает обезличенные
или синтетические снимки), рамки техники — эталонная разметка сцены; её читает демо-детектор. С подключёнными весами
RF-DETR (ML-часть) сервис распознаёт любые реальные снимки, а демо-проекты по-прежнему загружаются с эталонной разметкой.

Пересоздать: `python tools/make_demo_data.py` (нужен Playwright с Chromium для отрисовки сцен).

| Папка | Содержимое |
|---|---|
| `projects.json` | список демо-проектов |
| `<проект>/schedule_*.xlsx` | календарный график с кодами справочника, захватками, датами и техникой |
| `<проект>/site.json` | зоны, камеры с полигонами зон, заявленная общеплощадочная техника |
| `<проект>/snapshots/*.jpg` | снимки камер, время — в имени файла и на кадре |
| `<проект>/snapshots/*.json` | эталонная разметка: класс, уверенность, рамка; для кадров общего плана — стадия и готовность |
